PHysicalTDA.BandQFIResult — Type
BandQFIResult

Band-resolved QFI returned by band_qfi. With nb bands and nq momenta:

  • total :: QFIResult over all included measured bins.
  • FQ, σFQ :: nb × nq band contributions F_Q^(b)(q, T) and uncertainties.
  • FQres, σres :: residual F_Q^(res) from included bins outside every support.
  • ξ, σξ :: nb × nq relative contributions F_Q^(b) / F_Q (Eq. S31) and their uncertainties; NaN where F_Q ≤ 0. The denominator is the QFI over the measured domain, i.e. ξ_b^obs when only part of the spectrum was measured.

total.FQ == vec(sum(FQ; dims=1)) .+ FQres up to rounding.

PHysicalTDA.ComponentResult — Type
ComponentResult

One retained connected support component of a parent band.

  • weight :: plain sum Σ I(qᵢ, ωⱼ) over the component pixels (no ΔqΔω factor). The integrated weight of the manuscript, W = Σ I Δq Δω, is weight * mean(diff(qs)) * mean(diff(ωs)). Relative weights are unaffected.
  • bandIq :: Σⱼ I(qᵢ, ωⱼ) Δω over component pixels (energy-integrated).
  • bandIω :: Σᵢ I(qᵢ, ωⱼ) Δq over component pixels (momentum-integrated).
  • qinds, ωinds :: bounding-box index ranges; linear_indices gives exact pixel membership.

Supports are thresholded cores of each band, so marginals summed over the components of a parent retain only part of the band's total spectral weight (roughly 70% for isolated, noise-free Lorentzian bands with the default support settings).

RidgeRecoveryParams(; kwargs...)
RidgeRecoveryParams(ωs; max_slope, kwargs...)

Settings for find_ridge_candidates and recover_child_ridges. Energies are in the units of ωs, momenta in the units of qs, and slopes in energy per momentum unit.

The keyword constructor's defaults are the manuscript values (powder SEQUOIA data, 0.1 meV energy bins).

The second constructor is a preset for coarse, resolution-matched grids, written in units of the energy bin Δω = mean(diff(ωs)): half-maximum supports (support_fraction = 0.5), support_max_half_width = 2Δω, support_touch = Δω, prediction_scale = Δω, fallback_window = Δω, and min_child_q_fraction = 0.15. max_slope (the largest expected |dω/dq|, with some margin) is required. PHysicalTDA.adaptive_autosplitbands2d — Method
adaptive_autosplitbands2d(Iqω, qs, ωs; kwargs...)

Segment a 2D intensity matrix Iqω into physically tracked parent bands and connected support components. The first dimension is momentum q, the second is energy ω.

Returns a named tuple containing parent tracking data, final components, component counts, smoothed support images, resolution estimates, bridge statistics, and optional ridge-topology split/merge diagnostics.

Key options include periodic_q, resolution_q, resolution_ω, parent_count_method, max_bands, pixel_adjacency, and ridge_* controls. Use pixel_adjacency=:edge for edge-sharing support and :full for the full 3×3 neighborhood excluding the center pixel.

qs and ωs may be any real vectors, including ranges.

Periodic momentum axis

periodic_q=false (default) treats the first and last momentum rows as boundaries. Pass periodic_q=true only when qs spans a full period of reciprocal space; this wraps the end rows together in smoothing, centre imputation, gap repair and component labelling. The ridge graph uses ridge_periodic_q, which also defaults to false.

Changed default

Earlier versions defaulted to periodic_q=true. Pass periodic_q=true explicitly to reproduce results computed with those versions.

ridge_beta1 in the result counts accepted split–merge events, not the graph cycle rank; see RidgeTopologyResult.

band_dependence(br::BandQFIResult; m=1, nσ=2, bound_kwargs...)

Leave-one-band-out test of a certified witness. For each band b,

nQFI_lb^(−b) = nQFI_lb − F_Q^(b) / B,

using the point estimate F_Q^(b) and the bound B from qfi_bound (S/N, spins or bound, and ncomponents). Returns a named tuple

  • certified_without :: nb × nq, whether the certificate survives removing band b.

PHysicalTDA.band_qfi — Method
band_qfi(S, supports, ωs, T; σ=nothing, ωrange=(0, Inf), Δω=nothing, kB=KB_MEV_PER_K)
band_qfi(S, result, ωs, T; support=:components, kwargs...)

Band-resolved QFI (Eq. S29) for disjoint supports C^(b), given either as a vector of nq × nω Bool masks or as an adaptive_autosplitbands2d result (see band_supports). Keywords are as for qfi.

The decomposition is linear in S for fixed supports and exact over the measured bins: F_Q = Σ_b F_Q^(b) + F_Q^(res). Overlapping supports raise an error.

The supports must be on the grid of S. The segmentation itself is data-dependent, so it is usually run on the intensity map and the supports are then applied to the converted S_mag on the same grid.

PHysicalTDA.betti_curve — Method
betti_curve(PDs, τ; dims = 0:1, interval = :closed)

Compute per-dimension Betti curves βp(τj) on a user-provided grid τ.

  • PDs :: Vector of Ripserer PD (grouped by degree).

PHysicalTDA.build_ridge_topology — Method
build_ridge_topology(Iqω, qs, ωs; kwargs...) -> RidgeTopologyResult

Build the ridge graph of an intensity map Iqω (rows indexed by qs, columns by ωs) and return its topology as a RidgeTopologyResult.

  1. In each q-slice, keep up to max_peaks_per_slice peaks of the ω-profile smoothed with radius smooth_radius_ω, discarding peaks scoring below relative_score_floor times the slice maximum (and below min_prominence, when given).
  2. Link peaks in neighbouring q-slices. Equal peak counts are matched in ω order within max_jump_bins. A 1 → 2 or 2 → 1 change is linked as a split or merge when the branch separation lies between min_branch_separation_bins and max_branch_separation_frac * length(ωs); otherwise the nearest peak is linked. With periodic_q=true the last slice also links to the first.
  3. Add split–merge pattern edges and accept split–merge cycles that span at least min_cycle_q_fraction of the q-range, have two peaks in at least min_two_peak_fraction of slices, and reach confidence min_cycle_confidence.
  4. Report beta0 (connected components of the graph) and beta1 (number of accepted split–merge events; the raw cycle rank is in diagnostics[:raw_beta1]), and rasterize the graph into ridge_mask with tube radius tube_radius_ω. Pixel components of the mask are labelled with pixel_adjacency connectivity.

PHysicalTDA.loadHDF5 — Method
loadHDF5(fname; keypath=nothing) -> data

Load data from an HDF5 file.

Arguments

  • fname::String: Filename without .h5 extension
  • keypath::Union{String,Nothing}: HDF5 internal path to specific dataset or group. If nothing (default), loads entire file structure as nested Dict.

Returns

  • Dict{String,Any}: Nested dictionary mirroring HDF5 hierarchy, or the specific dataset/group if keypath is provided

Examples

# Load entire file structure
data = loadHDF5("crystal-data")
data["crystals"]["La2CuO4"]["LSWT"]["Temp"]["0K"]["H"]["intensities"]  # Access nested data

#Load specific group
LCO_data = loadHDF5("crystal-data"; keypath="crystals/La2CuO4/LSWT")
LCO_data["Temp"]["0K"]["H"]["intensities"]  # Only La2CuO4 LSWT data loaded

#Load specific direction
H_data = loadHDF5("crystal-data"; keypath="crystals/La2CuO4/LSWT/Temp/0K/H")
H_data["intensities"]  # Only H-direction data

#Load specific dataset (array)
intensities = loadHDF5("crystal-data"; keypath="crystals/La2CuO4/LSWT/Temp/0K/H/intensities")
#intensities is now a Matrix{Float64}

#Load q-points
qpoints = loadHDF5("crystal-data"; keypath="crystals/La2CuO4/LSWT/Temp/0K/H/qpoints")

Notes

  • HDF5 hierarchy uses "/" as path separator (like filesystem paths)
  • Use keypath to load only what you need (faster for large files)
  • Returned structure depends on what's stored at keypath:
    • Group → Dict with nested structure
    • Dataset → Array or scalar value

PHysicalTDA.pd_array_intensities — Method
pd_array_intensities(A; maxdim=1, threshold=nothing, superlevel=true, normalize=false,
                     make_death_finite=true, essential_cap=:max_death)

Compute persistence diagrams of an intensity array using a cubical complex.

Input:

  • A :: N-dimensional intensity array (non-finite entries are replaced by 0)
  • maxdim :: maximum homology degree p
  • threshold :: fractional filtration cutoff (see below); nothing uses the full range
  • superlevel :: superlevel (true) or sublevel (false) filtration
  • normalize :: min–max normalize A to [0, 1] before filtering
  • make_death_finite :: replace infinite deaths by a finite cap
  • essential_cap :: cap used for infinite deaths when make_death_finite=true

Returns:

  • PDs :: persistence diagrams {Dₚ} for p ∈ [0, maxdim]

Filtration values

The filtration is computed on Z, not on A:

superlevelnormalizeZ
truefalse-A
truetrue1 - Â
falsefalseA
falsetrueÂ

where Â = (A - min A)/(max A - min A). Births and deaths are reported in Z units, so for superlevel filtrations they are negated (or complemented) intensities and lifetimes are death - birth ≥ 0.

Threshold

threshold is a fraction (not a percent):

  • normalize=false: superlevel keeps cells with A ≥ threshold * maximum(A); sublevel keeps cells with A ≤ threshold * maximum(A) (for A ≥ 0).
  • normalize=true: the fraction refers to the normalized range, i.e. superlevel keeps Â ≥ threshold and sublevel keeps Â ≤ threshold.

Infinite deaths

With make_death_finite=true, each infinite death is replaced by a cap:

  • essential_cap=:max_death (default, historical behaviour): the largest finite death in that degree, or maximum(births) + max(1, 0.05max(|bmax|, 1)) when no finite death exists. The essential class then depends on the other features of the diagram.
  • essential_cap=:threshold: the filtration value at which the complex is complete (the full-range maximum of Z, or the threshold). For a superlevel filtration this is the background (minimum) intensity level, so the essential H₀ lifetime equals the peak-to-floor contrast.

The returned diagrams are rebuilt from (birth, death) pairs and do not carry Ripserer's representative/simplex metadata.

PHysicalTDA.qfi — Method
qfi(S, ωs, T; σ=nothing, mask=nothing, ωrange=(0, Inf), Δω=nothing, kB=KB_MEV_PER_K) -> QFIResult

Momentum-resolved QFI F_Q(q_i, T) = Σ_j K_T(ω_j) S(q_i, ω_j) Δω_j over the bins with ω_j > max(ωrange[1], 0) and ω_j ≤ ωrange[2].

  • S :: nq × nω dynamical structure factor; rows are momenta, columns the energies ωs. Pass the component-summed S_mag for the component-summed QFI.
  • σ :: optional nq × nω standard deviations of S; bins are treated as independent, so σFQ² = Σ_j (K_T Δω_j σ_ij)².
  • mask :: optional nq × nω Bool matrix; only true bins are summed.
  • ωrange :: energy window; set ωrange[1] above the elastic line to exclude it.
  • Δω :: bin widths (scalar or vector); inferred from ωs by default (energy_bin_widths).

Bins where S (or σ) is NaN are treated as unmeasured and skipped. Because K_T ≥ 0, restricting the sum to measured bins of a non-negative magnetic response gives a lower bound on the full integral; subtracted backgrounds that leave negative bins are summed as they are.

PHysicalTDA.qfi_bound — Method
qfi_bound(; S=nothing, N=nothing, spins=nothing, bound=nothing, ncomponents=3)

Separable (1-producible) bound B used to normalize the QFI, nQFI = F_Q / B. Give exactly one of:

  • S (and optionally N, default 1): N sites of equal spin S, B = 4 n_c S² N (12 S² N for the component-summed response, Eq. S28).
  • spins: the spin of every site in the normalization volume, for systems with several magnetic species or spin sizes, B = 4 n_c Σ_n S_n².
  • bound: B itself, for local operators other than spin components.

n_c = ncomponents is the number of spin components summed in S(q, ω) (3 for S_mag).

For local operators with ranges Δ_n = o_max − o_min, any m-producible state satisfies F_Q ≤ m Σ_n Δ_n² (Cauchy–Schwarz on each block of at most m sites), and Δ_n² = 4 S_n² for a spin component. Hence nQFI > m certifies at least (m + 1)-partite entanglement; for equal spins this is the bound of Eq. S26.

PHysicalTDA.qfi_kernel — Method
qfi_kernel(ω, T; kB=KB_MEV_PER_K)

QFI kernel K_T(ω) = 4 tanh(βω/2) (1 − e^{−βω}) with β = 1/(kB*T).

ω is an energy transfer and T a temperature; with the default kB they are in meV and K. The kernel is the positive-frequency form, so it returns 0 for ω ≤ 0. It satisfies 0 ≤ K_T ≤ 4, tends to 4 as T → 0 (T == 0 returns exactly 4 for ω > 0), and behaves as 2(βω)² for βω ≪ 1.

PHysicalTDA.rebin_to_resolution — Method
rebin_to_resolution(I, qs, ωs; σ=nothing, valid=nothing, resolution_q=nothing,
                    resolution_ω=nothing, factors=nothing, fill=:noise_floor,
                    average=:valid) -> RebinResult

Average I (nq × nω, rows = momentum, columns = energy) over blocks of qfactor × ωfactor bins, where each factor is the resolution width in bins, clamp(round(Γ/Δ), 1, n).

The widths Γq, Γω come from resolution_q, resolution_ω when given, and are otherwise estimated from the data as in adaptive_autosplitbands2d. factors = (qfactor, ωfactor) sets the block size directly. Trailing bins that do not fill a block are dropped.

Unmeasured bins are those with valid[i, j] == false; by default every non-finite I (or σ). They are given the value set by fill: :noise_floor (the smallest positive measured value) or :zero. The resolution estimate is made on this filled map.

average selects how a block is averaged:

  • :valid (default) averages only the measured bins, so unmeasured bins do not bias a block. A block with no measured bins holds the fill value.
  • :all averages every bin of the filled map, which reproduces the manuscript workflow (fill first, then block means).

With σ, the block uncertainty is sqrt(Σ σ²) / n over the measured bins, where n is the number of bins averaged; blocks without measured bins have σ = NaN.

Use upsample_mask or band_supports(result, rebin) to map masks on the rebinned grid back to the original bins.

recover_child_ridges(candidates::RidgeCandidates) -> ChildRidgeResult
recover_child_ridges(I, qs, ωs; params=RidgeRecoveryParams(), periodic_q=false) -> ChildRidgeResult

Child ridges inside connected parent supports.

  1. Support groups that overlap (within support_touch) in neighbouring momentum rows are joined into parents; parents spanning less than min_parent_q_fraction of the momentum axis are dropped.
  2. A parent has k children when at least min_child_q_fraction of its rows contain ≥ k support groups (at most max_children).
  3. The children are tracked across momentum by assigning candidates with a cost on the deviation from the predicted energy, the change in slope, slopes above max_slope, and candidate intensity. Where fewer candidates than children are found, the best point inside the parent's support near the prediction is used.
  4. The tracks form a ridge graph whose split, merge and crossing points are reported.

Use child_ridge_dispersions for the tracks as variable-length segments. The second form runs find_ridge_candidates first.

PHysicalTDA.slice_partition_marginals — Method
slice_partition_marginals(Sqω, ωs; pers_ratio_min=2.0, row_spacing=1.0, peak_selection=:height)

Partition each row of Sqω along the column-coordinate grid ωs using 0D persistent homology. Formerly naivesplitbands, which remains an alias. Return (bandIq, bandIω) with dimensions (Nbands, size(Sqω,1)) and (Nbands, size(Sqω,2)), respectively.

bandIq integrates over columns with Δω = ωs[2] - ωs[1] (unchanged). bandIω integrates over rows with the optional row_spacing factor. The default row_spacing=1.0 reproduces the historical unweighted row sum.

For physical integration, use uniformly spaced coordinates with a positive row spacing; partition_marginals(...; grid_weighting=:physical) validates both grids.

What the partition counts

For each row, the superlevel H₀ lifetimes are sorted, ℓ₁ ≥ ℓ₂ ≥ …, and the local count is the position k of the largest consecutive ratio ℓₖ/ℓₖ₊₁ (or 1 if that ratio is below pers_ratio_min). Consequences:

  • A row with exactly n noise-free peaks and no further bars returns at most n - 1 (a single clean two-peak row returns 1), because there is no ℓₙ₊₁.
  • In rows dominated by noise the largest ratio can fall between two noise bars, so the local count can be large.
  • Nbands is the maximum local count over all rows, so it can vary from sample to sample and rows b beyond a row's local count are zero.

The output is therefore a slice-wise, persistence-gated partition of the full 2D intensity distribution rather than a set of tracked physical branches; band index b is a local ordinal in each row. This is the behaviour used in the manuscript benchmark and is preserved by default.

Peak placement

  • peak_selection=:height (default, historical): the k partition centres are the k highest local maxima of the row.
  • peak_selection=:persistence: the centres are the birth locations of the k most persistent H₀ classes, so low-persistence maxima on the shoulder of a strong band are not chosen over a weaker but persistent band. The local count k is unchanged.

PHysicalTDA.symmetrize_q — Method
symmetrize_q(S, qs; σ=nothing, minus=q -> .-q, atol=1e-8) -> (S, σ, partner)

Symmetrize S(q, ω) over q and −q: row i becomes [S(q_i, ω) + S(−q_i, ω)] / 2.

The positive-frequency QFI of Eq. S25 assumes S(q, ω) = S(−q, ω). In general the momentum-resolved QFI, F_Q[X̂_q] + F_Q[Ŷ_q] with the Hermitian quadratures of Ô_q, is

F_Q(q, T) = ∫₀^∞ K_T(ω) [S(q, ω) + S(−q, ω)] / 2 dω,

so applying qfi to the symmetrized S gives the QFI without assuming inversion symmetry; for a symmetric response it changes nothing.

  • qs :: momenta of the rows, as numbers, tuples or vectors (e.g. (h, k, l)).
  • minus :: map from q to the momentum paired with it, −q (.-q) by default. Supply an equivalent point (e.g. −q + G for a reciprocal-lattice vector G) when −q itself is not on the measured path and the response is periodic.
  • atol :: tolerance for matching minus(q_i) to a row, as a Euclidean distance.
  • σ :: optional uncertainties, combined as √(σ_i² + σ_j²)/2 for i ≠ j.

Rows whose partner is not on the grid, and bins where either partner is NaN, become NaN (unmeasured). partner[i] is the matched row index, or 0 when there is none.

PHysicalTDA.to_smag — Method
to_smag(I, Qmag; form_factor, σ=nothing, g=2, polarization=3/2, scale=1) -> (S, σ)

Convert a background-subtracted magnetic intensity I(q, ω) (nq × nω) into the component-summed S_mag(q, ω):

S_mag = scale × polarization × I / ((g/2)² F(|Q|)²).
  • Qmag :: |Q| in Å⁻¹, either one value per row (nq) or one per bin (nq × nω).
  • form_factor :: required. The magnetic form factor of the ion, as a function of |Q| or as ⟨j₀⟩ coefficients (A, a, B, b, C, c, D) (see magnetic_form_factor). Pass Q -> 1.0 to skip the correction.
  • g :: Landé g-factor (spin-only value 2 by default).
  • polarization :: ratio of the component-summed response to the unpolarized cross section. Unpolarized neutrons measure Σ_α (1 − Q̂_α²) S^αα; for an isotropic response this is 2/3 of S_mag, hence the default 3/2. Supply the appropriate factor for an anisotropic response.
  • scale :: absolute-normalization factor. With the unpolarized magnetic cross section d²σ/dΩdE = (γr₀)² (k_f/k_i) [(g/2)F(Q)]² e^{−2W} Σ_αβ (δ_αβ − Q̂_αQ̂_β) S^αβ, scale converts I (in absolute units) to S per magnetic ion: divide by (γr₀)² ≈ 0.2905 b, by k_f/k_i and e^{−2W} if not already removed, and by the number of magnetic ions in the normalization volume.

Returns the converted S and, when σ is given, its uncertainties (scaled the same way; the uncertainty of scale itself is not propagated). NaN bins stay NaN. Applying the conversion is the caller's choice: none of the QFI functions apply it implicitly.
